# Reference copy: Experiments 4 and 5 (Pradeep)

[nov_17_pradeep_RESULTS.md](nov_17_pradeep_RESULTS.md) is a verbatim copy of
the team handoff file `team-handoff/nov_17_pradeep_RESULTS.md`, which is not
tracked in git. It is kept here so that the links from
[CAPSTONE_FINAL_REPORT.md](../CAPSTONE_FINAL_REPORT.md) resolve in the
committed tree.

The handoff did not include the figure files the notes link to. The 11 PNGs
under `charts/` and `e4-ramp-s1/` were extracted, unmodified, from the
handoff's own PDF export (`team-handoff/nov_17_pradeep_RESULTS.pdf`). Each
was saved under the file name its link expects, in document order, and
checked by eye against its caption.

The raw run folders for these experiments (`e4-ramp-s1`, `e4-ramp-s2`,
`e5-flood-*`, `race`, plus CSVs and tools) are not part of this copy.
